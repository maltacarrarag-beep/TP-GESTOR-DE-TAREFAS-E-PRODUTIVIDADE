# TP-PDS2-Gestor de Tarefas e Produtividade

O Agile Manager é uma ferramenta de terminal criada para facilitar a organização de equipes e o acompanhamento de projetos. Inspirado em modelos como o Kanban, o sistema permite distribuir tarefas entre os membros do grupo, organizar o que precisa ser feito e acompanhar o progresso de cada etapa em tempo real. O diferencial é o foco em produtividade: o programa ajuda a identificar quem está sobrecarregado e onde o trabalho está ficando travado, garantindo que a entrega final aconteça sem atrasos e de forma organizada.
