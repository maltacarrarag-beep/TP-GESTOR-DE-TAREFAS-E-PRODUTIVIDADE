Detailed Description

Banco de dados central do sistema Kanban.

Gerencia todas as colunas, tarefas e membros do projeto. E responsavel pela criacao, edicao, remocao e movimentacao de tarefas, alem do controle de carga dos membros. Detem a propriedade (ownership) de todos os objetos Coluna, Tarefa e Membro — libera a memoria no destrutor.
