Detailed Description

Representa uma coluna do quadro Kanban.

Cada coluna agrupa tarefas de um mesmo status (ex: "A Fazer", "Em Andamento", "Concluido"). Nao gerencia a memoria das tarefas — apenas armazena ponteiros. A responsabilidade de deletar as tarefas e do Quadro.
